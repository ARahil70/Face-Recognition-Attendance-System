# Security

CampusFlow is a local prototype. The dashboard server binds to 127.0.0.1; it has no login, administrator roles, encrypted database or liveness check. Do not expose it to the internet or another campus computer.

Do not report a vulnerability using a public issue if the report would include face images, student names, attendance records or other private data. Contact the project owner through a private university channel and share the smallest safe reproduction possible.

Never include face samples, the SQLite database, exports, model files or credentials in a pull request.
